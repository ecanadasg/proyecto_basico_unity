# proyecto_basico_unity
Demostración técnica en Unity (C#) de un juego básico de acción 3D. Incluye control de un caballero con mecánicas de combate (espada y escudo), sistema de eliminación de varios enemigos, animaciones de Mixamo, build funcional con su correspondiente ejecutable y documentación sobre cómo ha sido desarrollado el proyecto.

## Probar el Juego (Ejecutable)

No necesitas tener Unity instalado para probar el juego:

1. Clona o descarga este repositorio.
2. Navega a la carpeta `/Builds`.
3. Ejecuta el archivo **`proyecto Unity.exe`**.

---

## Controles

| Acción | Tecla / Control |
| :--- | :--- |
| **Movimiento** | W / A / S / D |
| **Salto** | Barra espaciadora |
| **Ataque** | Click izquierdo |
| **Defensa** | Click derecho |

---

## Estructura del Repositorio

* `/Assets`: Código fuente en C#, materiales, prefabs y escenas del proyecto.
* `/Builds`: Ejecutable compilado para Windows listo para jugar.
* `/Docs`: Documentación adicional y diseño.
